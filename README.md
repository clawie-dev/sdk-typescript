# @clawie-dev/sdk

TypeScript SDK for the Clawie REST + WebSocket API ([spec 023](https://github.com/clawie-dev/specs/tree/main/speckit/023-rest-api)).

Auto-generated from the OpenAPI spec, with typed handlers for every endpoint and topic-filtered WebSocket subscriptions.

## Install

```bash
npm install @clawie-dev/sdk
```

## Usage (sketch)

```typescript
import { Clawie } from '@clawie-dev/sdk'

const c = new Clawie({ host: 'http://localhost:3333', token: process.env.CLAWIE_TOKEN })

// Start a project
const project = await c.projects.create({
  brief: 'Build me a server monitoring SaaS',
  team: 'default-agency',
  budget: 20,
})

// Subscribe to live events
c.events.subscribe({ project: project.id }, (evt) => {
  console.log(evt.type, evt.payload)
})

// Decide an approval
const pending = await c.approvals.list({ status: 'pending' })
await c.approvals.decide(pending[0].id, { action: 'approve_with_rule', reason: '...' })
```
